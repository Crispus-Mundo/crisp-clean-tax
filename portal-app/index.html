Install

Open the portal now

iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen, then Add.

Android

  1. Open this page in Chrome.
  2. Tap Install the app above, or the ⋮ menu > Install app (or Add to Home screen).

Windows or Mac computer

  1. Open this page in Chrome or Microsoft Edge.
  2. Click Install the app above, or the install icon at the right end of the address bar.
  3. It shows up in your Start menu / Applications and can be pinned to the taskbar or Dock.

Safari on Mac: File > Add to Dock.

Your plan, numbers and documents stay behind your secure portal login. This app only opens the portal; it does not store any of your information on the device.
